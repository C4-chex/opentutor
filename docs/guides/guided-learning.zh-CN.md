# 苏格拉底 + 费曼引导教学

课程主页有“进入 AI 引导学习”，具体章节页顶部有“开始 AI 引导学习”。此入口沿用应用中已配置的真实模型；不以 mock 回答冒充教学。

教学循环：基础讲解与完整示例 → 理解检查 → 苏格拉底追问 → 费曼讲解 → 独立练习 → 近迁移检验。基础阶段先展示概念、必要先修知识、完整示例及常见误区，不显示答题框。用户点击“看完了，做个理解检查”后才开始一问一答；仅阅读不产生掌握证据。必要的原文外先修补充标注“AI 补充”。已有会话可补讲基础，再恢复原题及已有证据，不需要删除重来。AI 根据当前章节及其子文件备课，排除自动生成的目录说明；读取范围有限时在页面说明。

费曼环节由学生用自己的话解释，AI 作为零基础同学追问含糊之处。卡住时可点提示（0–4 级）或“讲解这一步”。接受帮助后，仍需通过新的独立检查，不能因看过解答直接升级。单说“懂了”、请求帮助、打开资料都不产生独立通过证据。

阶段由后端的教学状态机决定，前端不能直接提交“进入下一阶段”。答题评价需要引用学生本次回答中的真实文字。完成本轮需留下费曼、独立练习及迁移检验的作答；长期保持仍待延后复习，不自动改写既有全局掌握度百分比。

对话、提示级别、实际作答、知识漏洞与本轮证据存入现有数据库的 agent_kv，namespace 为 guided_learning，并按用户、课程、章节隔离。刷新可以续接；重复请求有幂等标识和版本检查。模型连接或格式失败时保留上一次成功进度，页面保留输入草稿。重新学习会归档旧轮次，不删除学习记录。

原始资料只作为教学数据，不授权执行代码或采纳其中的指令。每轮显示真实来源链接。教学会调用用户已配置的模型 API。现有知识库中的 raw/、画像和学习日志不会因为安装这一功能被改写。

设计参考：本工作区 knowledgebase-coach 教学协议、socrates/system.md 与 socrates/course_mode.md 中的一问一答、Hint Ladder、费曼角色及依据实际表现验证理解的规则。

验证覆盖先讲后练、完整示例、阅读不计掌握、旧会话补基础并恢复原题、提示不计独立通过、资料范围、权限、幂等请求、故障保留、草稿续接和中文界面。另用当前配置的真实模型验证合成教材，确认基础阶段先返回讲解与完整示例，进入理解检查后才出题；不以单一样例代表普遍准确率。

讲义支持短段落、独立代码单元、输出结果与 LaTeX 公式。代码可复制，按语言提示着色，展示与复制不执行程序。旧讲义中的纯文字计算会按原式分块显示，不重新计算、不改写已保存的内容；新生成的数学推导使用公式排版，整数除法保留取整含义。本轮来源收进“查看本轮原文”入口，同名文件带目录以便区分。
