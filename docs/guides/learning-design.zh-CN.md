# 导入资料驱动的学习应用：需求与分步实施

需求基线：2026-10-18。当前用户为自己或少量朋友使用，用户自行提供模型 API。

## 已确认需求

- 不预置示例课程和固定学习模板，以导入资料为起点。当前背景为 BME 初阶，涵盖 AI 训练、C/C++、Python、51、STM32、电路等。
- 支持网址（优先 GitHub）、PDF、PPT、Word。自动识别有教学价值的教程、代码、配置、图片等，不把全部文件等同于课程。
- 对关联章节和必要文件先提出抓取范围，经用户确认后导入，不随意扩展到其他网站。支持必要图片、图表及扫描页，识别失败或模型不支持时明确告知。
- 用户可以先说目标，也可以让 AI 推荐方向。筛选后先预览内容、理由和大纲，允许删选与调整。
- AI 按目标和基础重组连贯路线，保留前置依赖和来源。缺少基础时，说明后由用户决定是否加入；加入后由 AI 生成并标注“AI 生成的补充内容”。
- 首次启动必须明确选择：先讲后练/先试后讲；小提示/指出问题/完整讲解；相关练习中复习/仅手动复习。保存为画像，在设置中可修改。
- 用户可描述背景和进度，AI 按需用一两问补充画像，再通过简短诊断确定主题起点。自述与实际表现分开记录，不凭自述提高掌握度。
- 苏格拉底、费曼、示例与实操结合。问题应检查解释、推理、应用和迁移，避免低价值重复；约八成且主要目标达到后推进，不纠缠细节。
- 每小章安排 test；未达标时说明缺口，由用户选择补学、重测或继续。继续后保留待巩固项，按用户偏好复习。
- 需要时布置编程题。代码阅读、预测、独立编写、修改纠错均可，纠错题不占过大权重。无内置编译器，用户粘贴代码并描述思路；审阅不等于已实际运行。
- 独立作答与提示后完成分开记录，辅助后换新题复核。
- 学习页原始资料与 AI 教学并排，保留目录和进度，引用可定位。
- 教学报错支持讲解错误、判定错误、题目问题、资料识别错误，也允许自由填写。
- 基础体验：自动保存、断点续学、请求失败保留草稿。

## 分步安排

1. 首次画像、设置修改入口、服务端持久化、现有教学读取偏好；替换旧首次设置入口。
2. 教学报错记录及复核流程；画像按需澄清与主题诊断。
3. 智能筛选与范围预览、多文件课程大纲及来源对应。
4. 连贯章节教学、章节 test、适度推进、待巩固与按偏好复习。
5. 图表和扫描页理解、原文与教学并排，按实际模型能力验证。

后续步骤可以随实际依赖调整。移除旧入口不删除用户已有课程与学习证据；API 密钥不写入需求文档或测试夹具。

## 第一步的实际范围

新增 /welcome 首次画像；/setup 和 /onboarding 转入该流程。首页不再靠浏览器本地标志和课程数量判定完成设置。

新增 GET/PUT /api/learning-profile，画像按当前用户保存到现有 AgentKV，不新增数据库迁移。三个偏好必填，背景、进度和近期目标可留空。并发保存采用版本检查，防止覆盖其他页面的修改。

设置页顶部提供同一个画像编辑表单。当前引导教学在每次操作时读取最新偏好：开场讲解方式、错误反馈程度、用户自述背景。复习偏好已保存，后续复习流程按第四步接入。

本步没有声称已经完成 AI 澄清访谈、章节 test、智能筛选或图片理解。原有课程学习区域中的旧模板入口将在后续课程界面重做时替换。


## 第二批：本地进度与教学问题恢复

- 修复首页在 LOOM 未启用时仍逐课程请求知识图谱、产生多条错误提示的问题。图谱和预测统一先检查功能开关；已启用功能的真实错误仍正常展示。
- 引导学习的答案草稿按课程和章节保存在当前浏览器，成功提交后才清除。教学对话、判定和证据继续保存在本地 SQLite 数据卷。
- 每轮新教学更新前，在同一事务中保存上一状态的本地恢复点。可撤回上一轮教学，恢复问题、阶段、证据和待巩固项；被撤回内容仍保留。撤回不调用模型，网络重试不会重复撤回。
- 旧记录从下一次更新开始积累恢复点，不伪造历史恢复点。重新学习仍保留旧会话。
- 教学页新增“反馈教学问题”，支持讲解、判定、题目、资料识别和自定义说明。保存对应教学上下文，按当前用户隔离，提交反馈不修改学习成绩，也不标记为已复核。
- 本批没有加入自动 AI 复核、诊断访谈、章节 test 或跨知识点的八成推进规则；这些仍按后续计划实施。
- local-backups/ 保存独立的本地数据库备份并被 Git 忽略。备份不等于跨设备同步。


## 首页清理（用户要求）

首页辅助展示只保留 Agent 洞察，保留课程列表、新建/资料导入、GitHub 导入和设置入口。

删除截止日期、紧急复习、知识网络密度、待审批任务、模式建议，以及关联摘要、统计和学习节奏展示；移除它们的首页请求、动作、专用状态/文案和提醒初始化。

删除旧的首页面板集合和摘要/节奏组件。模式评估函数仍被课程内 Agent 使用，迁移至 lib/learning-mode-suggestions.ts 并保留原有验证，避免误删共用功能。后端课程/任务/复习接口、画像、导入、教学与本地数据未删除。


## Windows 原生运行迁移（2026-10-19）

已为当前电脑建立项目独立的 Windows Python 3.12 和 Node.js 运行环境，不修改 Anaconda。原生版使用 native-data 下的 SQLite、上传目录和私有模型设置；全部 33 张表逐表比对后，仅改写了两个上传文件路径引用。

提供 Start-OpenTutor.cmd / Stop-OpenTutor.cmd / Backup-OpenTutor.cmd。完整备份含数据库、上传资料和模型设置。旧 Docker 数据卷保留，旧容器停止且关闭自动重启；Docker Desktop 关闭时原生版仍能启动、读取资料和保存配置。

Windows 原生构建通过，教学/画像/GitHub 导入/原生模式后端 36 项和前端相关 28 项验证通过；文本 PDF、DOCX、PPTX、中文 Markdown 提取、真实模型调用和 GitHub 测试目录预览通过。未提交模拟学生答案到实际数据库。

代码执行后端显式设为 disabled，保留代码练习与 AI 审阅。实验功能和后续教学重构仍按原有计划，迁移不表示这些功能已完成。使用、数据位置和回退注意事项见 windows-native.zh-CN.md。
