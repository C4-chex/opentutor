# 学习速度（2026-10-19）

首页右上方新增“学习速度”按钮，位于新建学习空间按钮旁。提供“慢一点 / 按画像调整 / 快一点”三档。

## 画像与个性化

学习基础（刚入门 / 有一些基础 / 基础扎实 / 不确定）、学习要求（核心内容 / 独立实操 / 深入理解 / 不确定）与默认速度保存在同一份本地用户画像中。新用户首次画像明确选择；设置页可继续修改。旧画像按“基础/要求不确定、速度按画像调整”兼容读取，不猜测用户的能力，不重置其他偏好。

同一速度档不是固定倍速：基础与要求会共同决定每步相关概念数、建议讲解长度和独立练习任务数。例如“快一点”下，初学者仍用较小步骤、较多解释；已有扎实基础者可合并更多相关步骤。连续卡住时缩小步幅；连续独立答对时，“按画像调整”可以适当合并步骤。

讲解字数是给模型的建议预算，不是输出速度或精确时长保证。速度改变教学安排，不降低正确性标准，也不直接授予掌握度。

## 生效范围

- AI 导学每轮读取最新画像，调整教学步幅、讲解与练习安排。
- 独立练习阶段的任务数由服务端实际控制，全部完成后进入迁移检查。
- 快速模式仍保留苏格拉底引导、费曼解释、独立练习及迁移检查。
- 新生成测验会收到画像和节奏信息，用于题目内容与综合程度；题库批次仍遵循原有数量和质量规则。
- 已生成题目、已完成作答、旧教学历史不被重写。切换从下一轮教学或新练习生效。

## 保存与冲突

首页仅提交速度和当前画像版本，服务端合并更新。不会把学习背景、学习目标等字段清空。版本冲突会提示重新读取；保存失败仍显示之前已保存的速度。设置页与首页通过画像更新事件同步。旧版客户端省略新增字段时也不会重置已经保存的速度与基础。

相关接口：GET /api/learning-profile、PATCH /api/learning-profile/pace、PUT /api/learning-profile。

数据使用既有本地 AgentKV 用户画像，不新增数据库表，不依赖 Docker，也不会因点击速度按钮而调用外部 AI。

修改前数据备份：本机私有备份目录。

验证包含画像差异对应不同步幅、基础与要求共同影响练习量、保存冲突、续学使用最新速度、快速模式保留必要检验、首次设置和首页交互。测试使用隔离数据库与模拟模型，不写入真实学习记录。

最终验证：后端相关测试 100 项、前端相关测试 79 项通过。测试同时确认较慢节奏会要求更多独立练习，快速模式仍经过费曼解释、独立作答与迁移检查。生产构建包含 TypeScript 检查。
