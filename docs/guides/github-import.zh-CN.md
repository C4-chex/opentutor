# GitHub 原始学习资料导入

本地入口：http://localhost:3001/import/github 。首页侧栏和新建课程页面也有“导入 GitHub 教程”。

1. 输入公开 GitHub 仓库、tree 子目录或 blob 文件链接，点击“预览资料”。
2. 查看原文件内容并勾选需要学习的文件。测试文件默认不选，可手动加入。
3. 点击“导入所选资料”，创建独立学习空间。打开“原始资料”阅读，再结合问答或练习学习。

此实现复用 httpx 并直接调用 GitHub 的目录/文件接口，采用仓库整理为文本的方式，无需部署额外抓取服务。只读取指定子目录，固定到预览时的 commit，保留 Java、HTML、XML、配置和 Markdown 等原始文本。Thymeleaf 等 HTML 模板作为代码保存，不交给网页正文提取器。不会执行仓库代码，也不会在导入阶段调用 LLM 生成摘要。

资料按目录组织为课程内容节点；每个文件正文内附有固定版本的原文件链接。完整 Markdown 包可在导入成功页面下载。原始资料与导入来源也会保存在现有课程数据库和上传目录中。

预览有效期为 15 分钟，后端重启后需重新预览。只支持公开 GitHub 资料；无需提供 GitHub Token。GitHub 限流时会显示说明。为避免误导，不会把没有教程正文的代码仓库标称为完整教程。

限制：每次最多 100 个可读文本文件，总计 4 MB，每文件 256 KB；排除二进制、符号链接/子模块及常见构建目录。不处理图片 OCR、私有仓库或站外链接内容。分支名包含斜线时，URL 的分支段需使用百分号编码。目录过大请选择更小的子目录。

这个版本新增 GitHub 资料导入；普通网站继续使用原有单页链接导入，多页文档站抓取尚未接入。

验证样本：ityouknow/spring-boot-examples 的 master/spring-boot-thymeleaf。读取 28 个文件，推荐选择 26 个非测试文件，形成两个示例工程分组。来源版本为 53c8c8d6d0b957e9d4ae02f99d5993d5e699d522。

测试：后端目录范围、文件过滤、版本固定、预览权限、代码保留、数据库保存及导入幂等性；前端文件预览、选择导入、异常反馈、原文默认阅读，以及既有中文切换和首页导航回归。
