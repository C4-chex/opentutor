# 随问助手

页面右下角的“随时提问”用于学习过程中随手问小问题。首页、设置及课程页面均可打开；注册、登录和首次画像填写页面不显示。

## 提问与引用

- 小窗可展开、收起；收起后当前请求仍可继续完成，不会重新发起请求。
- 直接问术语、代码行或计算步骤，默认先简短解释，需要深入时继续追问。输入框中回车发送、Shift+回车换行；中文输入法选词时回车不会误发。
- 章节页面可以勾选“结合当前章节资料”。每次只发送有限原文片段和已显示的教学内容，不发送隐藏评分标准、其他课程资料或整本笔记库。
- 在课堂选中内容，点击“就此问 AI”；引用先进入小窗，确认后发送，不会自动调用模型。小窗打开时，也可点击“把选中文字带入提问”。引用可移除。
- 当前待答练习默认先给错误位置和方向提示；用户明确索要完整解答时可以展开，但不计作独立完成。
- 可复制回答，或在章节页点击“记入随堂笔记”。后者明确标注 AI 内容，按原有随堂笔记机制保存；须核对后使用。

## API 与隐私

复用“设置 → 模型与 API”中的主服务及原有故障切换规则，无内置云端账号，也无需为随问助手重复填写密钥。API Key 仍由后端保存，不传给聊天前端。

打开窗口、查看历史和编辑草稿不会调用生成模型。点击“发送”时才向配置的模型服务商发送问题、主动引用、近期对话、少量学习偏好（基础水平、反馈偏好和深度）及已启用的章节上下文。取消章节资料不会移除已有对话和主动引用；需要全新上下文时可移除引用并清空当前对话。

“随问助手”不调用课程 Agent 工具，不执行代码、不抓取新网址，也不更改教材、题目、掌握度或正式学习进度。代码结果仅作推断。章节原文和历史都有长度上限，回答可能有遗漏或错误；原文入口用于复核。

## 对话保存、失败和反馈

通用答疑、每门课程和每个章节分别保存完整对话到本机 SQLite。界面先显示最近 20 轮，点击“载入更早的对话”继续查阅；较早内容按批次存入 `quick_ask_archive`，不因轮数增加而删除。模型只接收最近 4 轮的有限片段；不会把完整历史反复发送。未发送问题与引用保留在当前浏览器页签的会话草稿中，刷新可恢复；清理浏览器数据或关闭页签后，草稿可能消失，已保存的对话不受影响。

网络或模型失败时保留输入；“停止等待”尝试取消未完成的服务端任务。取消与完成可能同时发生，可先刷新对话查看结果；相同请求的重试会复用已保存结果，避免重复生成或保存。另一页面抢先更新对话时，当前请求不会覆盖它，刷新记录后可继续发送。

“清空当前对话”需要确认，只清理当前范围的聊天记录，不删除收录的随堂笔记。回答下方有“反馈回答问题”，支持讲解有误、来源问题和自填说明。反馈及当时的问题、回答快照保存在本机；记录反馈不会触发 AI 复核、重新评分或自动修正回答。

## 课程 Agent

课程页面的小窗保留“课程 Agent”标签，可使用原有会话、课程工具及资料导入等能力。它与轻量随问助手的对话分开；课程工具仍可能按原有行为更改课程数据。

本轮不包含网页检索、图片问答、流式逐字输出、多设备同步或独立于主服务的第二套 API 配置。
