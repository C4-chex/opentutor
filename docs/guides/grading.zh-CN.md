# 提示式教学与轻量复核

练习流程：判断当前作答 → 指出一个卡点 → 给一个小提示 → 允许在原题上重试。默认不展示正确选项、最终数值、完整解法或参考代码。

## 当前行为

- 普通选择题、判断题和多选题直接按选项判断。复核也不再转入开放式作答的量规与两轮模型评估。整数运算题不再无故要求解释编程语言或边界条件。
- 常见整数运算和格式化题使用稳定的小提示；一般选择题可由 AI 根据实际选项内容给一次简短提示。提示生成失败不改变对错判断。
- 开放题保留明确要求、等价答案和真实作答证据检查，普通反馈仅做一次评估。数学等价表达不因未写成参考格式而扣分。
- 答错或部分正确后可直接重新选择或修改文字、代码。答对后不继续纠缠，用户可进入下一题。
- 提示只讨论原题，不换数字、不另出变式。确实有问题的题可以跳过。
- 评分明细从主界面移除；“反馈有问题”作为较小的可展开入口，原因选填。仍保留本地判定历史和版本检查。
- 对外反馈不包含标准答案、评分量规或内部解题解释。代码明确是静态审阅，不声称执行过。
- 看过提示后改对会保存为辅助完成，不重复制造一次独立掌握的证据；界面以正常教学反馈呈现，不堆积计分警告。

## 官方学习模式参考

官方说明强调引导思考、小步解释、检查理解和帮助纠错；这里借鉴这些公开交互原则，没有接入或声称复制 ChatGPT 的内部学习模式。

- https://help.openai.com/en/articles/11780217-using-study-mode-in-chatgpt
- https://learn.chatgpt.com/use-cases/build-exam-study-system

此前参考的 Anthropic Grader、DeepEval 和 Prometheus 的证据与量规思路仍用于后台的有限检查，用户学习过程不需要接受多轮审查。

模型可能误判，参考答案也可能有错。简单题优先使用确定性判断；遇到反馈问题，可通过教学报错入口提交或继续学习。
