# OpenTutor 简体中文补充包

此补充包接入项目原有的中文/英文切换，补齐模板、模块、问答、笔记、学习分析、错题、上传和常见报错文案。

- 界面语言：在设置的外观选项中选择“中文”。已选中文的浏览器刷新即可。
- 补充词典：`apps/web/src/locales/zh-ui.json`。英文键用于匹配界面文案，中文值可独立维护。
- 切换语言会更新组件，不会重置正在输入的内容或更改模块类型标识。
- 导入资料、课程标题、源文件、已生成的学习内容和 API 密钥不属于界面词典，不会自动改写。
- 未开启智能语义复习时，普通页面不再请求该实验接口；复习入口会显示中文说明，可继续使用测验和闪卡。
- 更新前端源码后，按仓库 README 或[原生运行说明](windows-native.zh-CN.md)重新构建并启动，再刷新浏览器。
- 此补充包针对当前本地版本制作，更新上游前请保留 Git 差异，避免直接覆盖新版本。
